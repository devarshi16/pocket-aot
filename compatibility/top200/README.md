# Historical 20-game sample

`results.json` is metadata from the frozen private random sample assessed on 2026-10-16. All 20 cartridge containers decoded. One game, **Dusk Child**, reached an RP2040 build and owner-confirmed display/controls on a Raspberry Pi Pico/Waveshare Pico LCD 1.3. The remaining 19 recorded an explicit first blocker. Removing a first blocker does not prove that the rest of a game will work.

The original game source, `.p8.png` cartridge payloads, generated native game code and UF2 firmware are not distributed. Paths in this metadata identify historical artifacts and are not live repository files. Authors, source links and SHA-256 values preserve experiment provenance. Repeating this private experiment requires obtaining cartridges separately from their authors under applicable terms; the public CI does not download them.

The separate public regression suite uses original included fixtures. See [Status](../../docs/STATUS.md) for the distinction between current public execution, implementation counts and historical game outcomes.
